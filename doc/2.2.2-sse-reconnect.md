# SSE robusto en d_rocket 2.2.2

`SseReconnector` mantiene una conexión Server-Sent Events y ofrece un ciclo de
vida controlable para aplicaciones offline-first. Esta versión no cambia el
build ni el codegen: el cambio está limitado al transporte realtime.

## Headers dinámicos

`headersProvider` se ejecuta antes de cada conexión, incluida cada
reconexión. Esto permite obtener el token vigente sin reutilizar headers
obsoletos:

```dart
final SseReconnector stream = SseReconnector(
  factory: HttpSseClient.new,
  url: Uri.parse('https://api.example.com/events'),
  headersProvider: () async => <String, String>{
    'Authorization': 'Bearer ${await session.accessToken()}',
  },
);
```

Cuando el servidor responde `401`, `onUnauthorized` puede renovar la sesión.
Si devuelve `true`, la siguiente conexión vuelve a consultar
`headersProvider`. Si devuelve `false`, el ciclo termina en `failed`. Un `403`
se reporta como `SseHttpException` y no inicia reintentos indefinidos.

## Estados y cierre

Los estados disponibles son `connecting`, `connected`, `retrying`, `stopped` y
`failed`:

```dart
final states = stream.states.listen((state) {
  print(state);
});

await stream.start();
await stream.stop(); // también cancela reintentos y el transporte activo
await stream.start(); // inicia una generación nueva
await stream.dispose(); // cierra también events y states
await states.cancel();
```

Las callbacks de una conexión anterior se ignoran después de `stop()` o de un
nuevo `start()`, por lo que un evento tardío no puede contaminar la generación
actual.

## Cursor y procesamiento manual

Por defecto, el cursor avanza cuando se recibe un evento con `id`. Para avanzar
solamente después de guardar o procesar el dato, activar `manualAcknowledge`:

```dart
final stream = SseReconnector(
  factory: HttpSseClient.new,
  url: Uri.parse('https://api.example.com/events'),
  manualAcknowledge: true,
);

stream.events.listen((event) async {
  await repository.save(event.data);
  stream.acknowledge(event);
});

stream.clearLastEventId();
```

El cursor se envía en `Last-Event-ID` durante la próxima conexión.

## Inactividad y heartbeats

`inactivityTimeout` reinicia el contador con cualquier actividad del transporte,
incluidos comentarios SSE (`: heartbeat`) que no contienen cambios de negocio.
Si vence, la conexión se cierra y entra al mismo flujo de reconexión controlada.

```dart
final stream = SseReconnector(
  factory: HttpSseClient.new,
  url: Uri.parse('https://api.example.com/events'),
  inactivityTimeout: const Duration(minutes: 2),
);
```

`HttpSseClient` cierra la suscripción de respuesta en `close()`. Cuando creó
internamente el cliente HTTP, también libera ese transporte; cuando recibe un
cliente inyectado, no lo cierra porque la propiedad pertenece al llamador.

## Otras mejoras de 2.2.2

La misma versión del framework y del builder también corrige el escape de
expresiones `@Pattern`, soporta modelos anidados nullable en el serializer y
permite cambiar `baseUrl` por instancia mediante `RestClientConfig`.

Los formularios generados aceptan validadores entre campos:

```dart
final form = PaymentRequestForm(
  validators: <FormValidator<PaymentRequest>>[
    (PaymentRequest? value) => value?.validateCard(),
  ],
);
```

También exponen `bindComposite()` para controles que producen varios valores:

```dart
form.bindComposite<String>((String value) => <String, Object?>{
  'expirationMonth': value.substring(0, 2),
  'expirationYear': value.substring(3),
});
```
